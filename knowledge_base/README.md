# OpsPilot Sample Knowledge Base

These are fictional, educational operational runbooks and incident reports created for the OpsPilot personal project. They are not vendor documentation and must not be treated as instructions for a real production environment.

- `incident_reports/incident_deployment_latency.md`
- `incident_reports/incident_redis_cache_miss_spike.md`

Copy the `runbooks/` and `incident_reports/` folders into your project's `knowledge_base/` directory.

## Safety
These examples are fictional. Diagnosis statements are hypotheses until supported by live evidence. Do not execute real production remediation based only on these documents. Start OpsPilot with read-only diagnostic tools; disruptive actions require explicit authorization and verification.
